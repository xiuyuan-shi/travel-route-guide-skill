# 获取实际地图与路线

先确定点位和游玩包围框，避免一次获取整个省／国家的道路。

可选助手（标准库，无 API key）：

```
python3 SKILL_DIR/scripts/fetch_map.py --bbox 120.28,36.03,120.42,36.09 --out work/basemap.geojson
```

该命令请求 OSM Overpass 的道路与海岸折线；坐标为 west,south,east,north，WGS84。海岸只画蓝线，不猜测哪侧是陆地。它不返回完整街道地址或行政区，不承诺所有国家都有完整数据。遵守服务限制，失败后保留已有文件，不循环重试；换可靠数据来源或明确降级。

需要全市范围：另找可信的行政边界（例如 OSM 已核实关系或政府公开 GeoJSON），加入 kind=boundary，再保留详细游览区视图。不要把旅行包围框称为全市边界。海岸／地形可用授权允许的地理数据，保留来源和许可。

步行路线可使用可用地图服务／OSRM 步行路由；公开演示服务要先核对使用政策，小量、串行、缓存请求。不得拿驾车路由充当步行路由。路线取得失败时用 status=schematic 虚线，并解释。默认地图不请求公共 OSM 瓦片；不通过伪造请求头或换受限瓦片域名规避服务限制。

生成后视觉检查河海、点位和路线相对位置。几何边界或坐标系不一致时先修数据，不用平移截图遮掩偏移。
